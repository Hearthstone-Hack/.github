## ❓ FAQ

### Do I need to run it as Administrator?

No. This repository is an informational reference and does not contain software that needs to be launched.

### Does this repository include a Hearthstone hack?

No. It provides reference material only and does not include executable hacks or game modifications.

### Are Hearthstone hacks allowed?

Blizzard's End User License Agreement prohibits unauthorized hacks, cheats, and bots. It defines hacks as accessing or modifying platform software in ways that Blizzard has not authorized.

### Can unauthorized modifications result in an account penalty?

Yes. Blizzard reserves the right to suspend or terminate access when users violate the applicable agreement.

### Is a deck tracker the same as a hack?

Not necessarily. Some deck trackers are permitted in specific contexts, while software that modifies the client or provides unauthorized information can violate Blizzard's rules. Tournament policies may impose additional requirements.
